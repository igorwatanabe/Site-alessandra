First, run the development server:

```bash
yarn dev

pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Instagram

The cards use the Instagram Graph API and display the three most recent posts
from the account associated with `INSTAGRAM_ACCESS_TOKEN`. Add a long-lived
Instagram access token to `.env`:

```env
INSTAGRAM_ACCESS_TOKEN=seu_token_do_instagram
```

The token must belong to the Instagram professional account whose posts should
appear on the site and include permission to read media. Without this variable,
the site uses the local fallback cards.

You can start editing the page by modifying `app/page.js`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/basic-features/font-optimization) to automatically optimize and load Inter, a custom Google Font.
